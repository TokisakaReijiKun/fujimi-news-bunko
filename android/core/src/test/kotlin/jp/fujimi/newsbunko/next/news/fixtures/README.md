# 官方结构回归样本

`live-2026-10-01.json` 于 2026-10-01 从六家官网取得，每条 `pages` 记录原请求地址、最终地址和当时响应中的 HTML／JSON。采样使用 Tokyo 中既有 `server.download`，保留 TLS、公开地址、重定向、超时及体积限制，没有调用翻译、下载媒体或写入用户文库。

样本保留官网实际卡片、正文容器、会员标记、JSON-LD、日经当前文章锁状态和 NHK 正文 API；删除无关 JavaScript/CSS、事件属性、其他无关属性、NHK 授权请求页面。`expected` 是 PC 对应来源模块当时验证成功的标题和完整原文段落，供 Kotlin 解析结果逐段对照。NHK 正文格式与全文不一致、Yahoo pickup 无正文链接的原站失败样本也保留为拒绝回归。

这些是带时间戳的结构样本。测试不访问网络；样本通过不能证明未来页面结构或当前手机网络可用。此次读取经开发机 HTTPS 代理，手机仍需使用实际网络验证。
