# Android 1.0.14：按用户截图复刻 MOJi 播放器

用户要求播放器完全参照 MOJi 阅读截图。本版撤销 1.0.13 的悬浮绿色卡片处理，以用户第二张截图和已提供 APK 的 `layout_audio_player_manager` 为依据。

## 外观

- 白色面板左右铺满、底部为 0，仅顶部 16px 圆角；没有外边框、投影或底部圆角。白色延伸至系统手势区。
- 时间 14px，左右内边距 16px。360px 基准下进度轨道位于 x60–300px，灰色轨道 4px，播放进度使用原版 `#e0315b`；移除大绿色拖动圆点。
- 中央按钮视觉盒为 36 / 40 / 36px，相邻间距 10px；前后图标 16px，播放图标 22px，播放背景 `#f8f8f8`。透明伪元素扩大触摸范围，不改变原版视觉尺寸。
- 左侧原耳麦图标位于 70×38px、16px 圆角浅灰入口，距左边 20px；右侧为原版 24px 六角设置图标和 10px 倍率角标。
- 默认系统底部安全区 24px 时，面板总高 110px。安全区计入面板内部留白，面板始终贴底。
- 系统大字体下，两端时间列和时间行随文字增大，倍率角标向上避让；默认字号的原版几何保持不变。
- 明暗及禁用资源均直接来自用户提供 APK，14 张 PNG 已按 SHA-256 核对。没有用自绘 SVG 或滤镜替代原图；资源记录为 `build/research/moji/native-layout/player-assets.json`，尺寸依据为 `player-exact-spec.md`。

## 交互范围

新闻和书籍复用播放器模板，保留三条播放路径、前后段、暂停、拖动及倍速。右侧设置入口操作已有倍速；左侧入口接入已有的听原文、对照阅读及重听本段。它不宣称提供 MOJi 的录音跟读训练系统。菜单可用键盘及 Android 返回关闭并恢复焦点。

正文仍采用上一版已统一的 16px 基准。未更改后端 API、存储格式或用户文库，不需要迁移或备份。

## 1.0.15：倍率角标贴合齿轮

修正上一版倍率相对外层按钮独立定位造成的垂直间隙。图标与数字现在共用 24×24px 定位锚点，按照原资源约束将文字左端置于图标左侧 +15px，文字底端置于图标底部 −16px；默认字号相较上一版下移 6px。字号放大时同样以图标为锚，不再另算独立的字体缩放偏移。
