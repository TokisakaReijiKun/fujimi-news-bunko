# Android 1.1.0：正式移动界面

按已确认的 Demo 2.46 将日刊、閲読室、书架、辞书、设置、收藏和两类阅读器移入正式 Android 资源。沿用原包名、签名、WebView、词典和 Media3；版本为 `1.1.0 / versionCode 23`，用于覆盖 `1.0.17-rollback / code 22`。

## 正式行为

- `static/index.html` 在 Android 桥存在时启用新界面。桌面不启用；浏览器验收可显式使用 `?mobile-redesign=1`。
- `mobile-app.js/css` 提供主界面；`mobile-reader.css` 与 `mobile-epub.css` 保留已确认的阅读排版，按原生系统栏安全区布局。
- 词典直接使用原有 DOM、查询和完整词库。声线试听使用原始参考 WAV，采用词典的喇叭与声波动效；不调用合成。
- 日刊任务、篇数、来源网址和配额设置使用实际 Android 接口，配额合计不能超过記事数。设置真实持久化。
- 文庫互联使用手机扫码／地址与配对码、真实同步进度及解绑流程；不显示 PC 专用的二维码管理界面。
- 收藏、书签与进度使用文件存储；删除日刊后收藏仍可独立读取自身附件与录音。进度只改 `state.json`。离开书页先保存位置，再停止滚动监听。
- DeepSeek 配置通过原 Android Keystore 接口保存，不回显或打包密钥。

本机 EPUB 导入和 Irodori 模型推理仍不在 Android 执行；书籍、正文与参考声线可通过既有 PC 同步补齐。章节重读沿用手机全局声线检查已同步录音，不暴露未实现的章节声线写入操作。

## 验证

- Android core：103 项通过，包含收藏事务恢复、独立附件、纵排负滚动位置、真实书籍状态与配额约束。
- `tests/verify_mobile_app.cjs`：375／390／1100px 六视图、两阅读器、返回、来源网址和配额；离开书页后的滚动不会覆盖保存位置。桌面原入口不挂载新界面。
- 专用 API 35 模拟器：18项离线设备用例通过；新增文章模板断言后的2项界面检查再次通过。已实测原生Media3文章播放、书籍阅读及隐藏书页进度保持、2秒合成参考WAV的实际播放与停止、状态栏安全区及系统夜间模式。未连接或安装到用户实体手机；测试使用隔离的合成内容。
- 最终构建、设备检查、APK 签名及资产核对结果位于 `build/qa/mobile-app/`。

本次未修改用户文库，没有数据迁移，也未创建备份。APK 仅包含正式资源与原始词典，不包含用户文章、电子书、用户参考录音或密钥。
