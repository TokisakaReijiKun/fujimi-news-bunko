# Android 1.1.1：阅读器样式统一

版本为 `1.1.1 / versionCode 24`，沿用原包名和签名，可覆盖安装 1.1.0。

- 新闻与电子书共用原电子书的 MOJi 播放器配色、尺寸、按钮排列和系统安全区。删除新闻专用的绿色覆盖；保留实际播放、段落跳转、倍速及听读菜单。
- 播放器与子元素关闭 WebView 默认蓝色触摸高亮，保留圆形按钮按下反馈及键盘可见焦点。
- 删除电子书自定义右侧滚动轨道及其事件监听；隐藏阅读正文原生滚动条，保留手势滚动和阅读进度保存。
- 电子书默认原文、译文、假名直接使用新闻的字体、字号、颜色、行距和段落间距变量。默认原文为 16px／32px、译文为 16px／28px，左右留白 28px；保留 EPUB 标题、插图及明确的文本格式。书签占用右侧留白，不再挤窄正文。
- 打包沿用工程当前的朗读正文高亮色 `#E0315B`，与 PC 使用同一全局样式。

修改仅在 Android 新界面标记下生效，桌面入口保持既有样式。没有用户数据迁移或备份。

浏览器验证覆盖 375／390／1100px，两类播放器在浅色、深色模式下的实际颜色与几何数值一致，触摸高亮透明；同时检查六个主视图、返回、配额约束、离开书页后不覆盖进度及原桌面入口。

设备截图、构建与签名核验记录保存在 `build/qa/mobile-app-1.1.1/`；本次仅使用专用 Android 模拟器和隔离内容，不安装到实体手机。

Android 实测两类单行 ruby 原文行框均为约 33.09px（CSS 行高 32px），译文行框均为 28px，字形和假名实际宽高一致。两播放器按住播放键均无蓝色方块；使用 6 秒本地录音实际播放、暂停正常，无控制台异常。两项设备界面检查通过。
