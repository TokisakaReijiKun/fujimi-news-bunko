# 1.1.14：手机声线管理与词条收藏入口

查词卡片中的星号保存的是词条 ID，沿用当前应用的 `fujimi-dictionary-favorites` 本地存储。现在可从手机「辞書 → 收藏」查看、打开词条详情和取消收藏，原有收藏无需迁移。

手机声线改成统一列表，移除「システム音声／参照音声」分组。支持添加 WAV 音频、修改显示名称、更换音频、删除声线；目录中的声线可改显示名、移除和重新添加。显示名保存在设置中，原声线 ID 和文件名保持稳定，不会因改名失去已生成音频的关联。删除当前声线后清空选择，停止把已删除声线用于即时朗读。

WAV 导入使用 Android 系统文件选择器，原生流式读取并检查 20 MiB、1–120 秒限制；没有将音频转成大段 base64 传给页面。替换文件先写临时文件、验证再原子提交，失败保留原文件。更换或删除只作用于当前手机；同步仍沿用现有补齐规则，不传播删除与最新编辑。模型合成能力没有扩展，手机的模型声线仍用于播放 PC 生成后同步的音频。

验证：121 项 core 测试无失败，含新增／替换 WAV、无效音频不覆盖、稳定 ID、改名、删除当前选择及目录移除恢复；375/390px 待打包页面通过完整增改删、文件选择回调、收藏查看／取消、详情返回和无溢出检查。原查词卡片、桌面划词及主应用页面检查通过。Android 编译与 Release 构建成功，同证书签名及 32 项界面／词典资源核对通过。未进行手机实机验证。

以 1.1.13 为资源基线，仅更改本次 4 个前端资源并编译所需 Android 管理接口，保留此前辞书及查词卡片修复。未更新 PC 客户端、改写活动文库、迁移数据或创建手工备份。安装包为 `dist/FujimiShinbunBunkoAndroid/FujimiShinbunBunkoAndroid-1.1.14-release.apk`，code37；证据在 `build/qa/voice-management/` 和 `logs/voice-manage-*.log`。
