# Android 1.1.17：去除点词未匹配提示

手机文章点词没有匹配词条时，关闭查询浮层并安静结束，不再弹出「該当する語が見つかりません。」Toast。上一版错误地把普通未匹配当成查询故障，也给分词结果中的标点创建了可点词节点；本版将纯标点、空白保留为原文文本，不触发查词。词库读取失败等实际故障仍明确报告。

未更改原 APK 点击函数、分词方式、词库查询规则或桌面选区查询。本轮没有数据迁移或备份。

375/390px 正式页面回归通过：标点不形成查词按钮且原文完整；多次未匹配无 Toast；正常点词、假名、选区、词卡、收藏与朗读定位保持可用。桌面选区查询回归通过。未在实体 Android 手机运行。
