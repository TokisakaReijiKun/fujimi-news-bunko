# 1.1.22：手机发起 PC 朗读

手机文章与书籍的参考声线、PC 本地模型声线新增远程生成流程：按已配对连接发起请求，复用 PC 的 TTSController、缓存、单队列和存储；轮询原任务进度，完成后按现有路径／大小补齐协议接收音频，再确认手机已能读取完整音频。手机仍不运行 Irodori 模型。

参考声线按实际 WAV 名称映射，不将手机数字 ID 当作 PC ID；内容按现有稳定同步 key 定位。缺失内容与声线使用既有同步传输补齐，不重新建立合成后端。状态、取消和错误沿用配对认证与网络限制。PC 模型或连接不可用时返回明确失败，不冒充生成完成。

手机失败提示使用 Toast；不再将长错误写入文章行内状态区。普通打开尚无参考声线音频的文章不会先报错，点击播放才向 PC 发起合成。桌面页面与静态资源不随此项更新改变。

手机包沿用 1.1.21 的声线设置更新。PC 增量 EXE 仅替换 server/device_sync 并新增 device_speech，其余原模块和启动脚本保持原编译内容。客户端重启会使旧配对会话失效，需要重新配对。

按用户要求未运行测试；JavaScript 与 PC 源码语法检查、Android release 和 PC EXE 构建完成。尚未进行实体手机端到端验收。无需迁移文库或创建备份。
