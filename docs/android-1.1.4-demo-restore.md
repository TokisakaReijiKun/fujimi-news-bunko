# 1.1.4：撤回未经确认的界面替换

按用户要求，以 `tests/mobile-japanese-design/next-ui.js` 的确认稿及其后明确要求为依据，恢复正式 Android App 的界面。此版本不更新 PC 客户端，不改写或迁移用户文库。

## 本次恢复

- 书架恢复「＋ 导入」「我的书籍／册」，撤掉替换进去的「同期／本棚」；原有封面、标题、作者排版保留。
- 阅读室恢复「または／本文を貼り付ける」及原正文表单入口，不再因 Android 环境隐藏。
- 电子书设置恢复章节声线下拉框、章节处理和原朗读按钮，不再替换为静态声线名称或「保存した朗読を読み込む」。用户已要求删除的译文查词设置、重复章节栏及右侧滚动条不恢复。
- 主设置页恢复「文庫の点検／操作説明」，撤掉「文庫の場所／この端末」及新增的顶层「アプリ」分组。已有密钥、蜂窝网络及定时权限配置保留在「文庫互联 → 翻訳と通信」，避免撤掉栏目后丢失配置入口。
- 撤销首页强制退出 Activity 的专门分支，恢复 WebView 历史返回；阅读器与弹窗优先关闭。初始 hash 使用 replaceState，使回到初始页时仍能正确显示日刊。
- 恢复旧收藏兼容：只有日刊收藏标记、没有独立收藏副本的文章仍可显示、打开和取消收藏。独立副本优先；读取不创建副本、不修改文件，无关未收藏文章的坏正文不阻塞收藏列表。

## 保留的明确要求及必要实现

新闻与电子书共用的播放器、无蓝色点击背景、字体与间距、原纸色、书签位置、日刊更新按钮位置、来源网址及配额、参考音频播放、原标语和 Tailscale 配对支持保留。实际收藏、书签和阅读进度继续保存，不倒退成预览状态。

手机端的扫描、六位码配对及同步仍由已接入的原生接口负责，不改成 PC 专用的二维码管理页面。此次没有启动实际 PC 程序、VPN、模拟器或手机，也没有进行登录和跨网验证。

## 检查与限制

- Android core 全部 110 项测试通过；新增旧收藏标记回归先复现为空列表，再确认恢复可读且文件未变。
- `tests/verify_mobile_app.cjs`：375／390／1100px，恢复入口、原章节控件、配置可达性、历史返回、配额、共用播放器、无蓝色点击背景及无右侧滚动条检查通过。
- `tests/verify_reader_typography.cjs`：375／390px 新闻与电子书字体、字号、颜色、间距及原 EPUB 格式检查通过。
- `tests/verify_pc_scope_restore.cjs`：1100／1440px PC 默认播放器、阅读排版和原控件对照通过；本次不向 PC 安装目录复制任何资源。
- JavaScript 语法检查和 release 构建通过，使用既有包名及发布签名，版本号 1.1.4/code27，可覆盖安装。

恢复界面控件不代表补齐尚未实现的 Android 服务：本地 EPUB 导入、粘贴后保存为文章、章节单独声线写入、章节增强及 Irodori 模型生成仍未接入。导入入口会明确说明限制，其他未支持 API 仍明确报错，不返回假成功。已同步正文和音频仍按原有接口读取。电子书封面破图本次没有定位或修复，不能将界面恢复当成封面修复。
