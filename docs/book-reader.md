# 书架与 EPUB 阅读器

## 参考与改动依据

提供的掌绿 APK 是 Flutter arm64 编译应用。其 `libapp.so` 包含 `Prixii/auto_novel_reader_flutter` 项目标识、`epubx` 解析器名称、目录与阅读进度相关符号。项目 README 说明了 EPUB 解析和 WebView 阅读方案。本项目参考这些功能边界，独立实现 Python/Web 版本，没有复制其 Dart 源代码。

参考：https://github.com/Prixii/auto_novel_reader_flutter （检查时 master：`6d6b9a68baf4d6846c3d31cfd795c26d43273b66`）。参考应用本身也记录了长文进度与封面识别等限制，不将其视为无缺陷模板。

## 存储

```text
data/books/书名/
  原始文件名.epub      原始导入文件，文件名与内容完整保留
  book.json            元数据、正式目录、章节清单与哈希、资源清单
  state.json           进度、书签、最后阅读时间与修订号
  chapters/0001.json   每个逻辑章节的正文块、译文和源文件位置
  resources/OEBPS/...  包内图片资源，保留原相对路径
  audio/               音频预留
```

书名冲突附加稳定编号，改标题不移动目录。`book.json` 的 `source_file` 和 `source_sha256` 记录原 EPUB 文件名与内容校验值，加载时验证原文件存在且内容未变。`data/fujimi.sqlite3` 的 `books` 表只存书架索引，不再存整本书的 payload。目录、章节和状态可独立恢复；“文庫刷新”能从有效书籍目录重建索引。每本书只保留一个段落书签，新增书签会替换旧书签；书架入口优先恢复该书签，没有书签时才恢复普通阅读进度。进度百分比按当前章节内容计算，不跨章节累计。书籍进度更新仅写 `state.json`，不重写整本书。书籍内容更新使用恢复日志和已校验章节哈希；重新启动会继续尚未完成的提交。

应用内删除将书籍目录归档到 `data/backups/`。用户在文件系统删除目录后，刷新清理失效索引；此时备份只能保留残留索引，已被用户删除的原文件、章节和状态不能凭索引恢复。不要再依赖数据库备份代替书籍目录备份。

## 解析与阅读

- EPUB3 优先使用 nav 文档的 `epub:type=toc`，兼容 EPUB2 NCX；保留目录层级和锚点。
- Spine 决定正文顺序，顶层目录条目划分逻辑章节。未列入目录的连续 XHTML 保留在所在章节中，前付单独保留；不再把每个重复 `<title>` 当作章节名称。
- 图片、ruby、内链锚点、强调及允许的文本排版保留。SVG 封面中的包内栅格图转换为图片，不丢弃封面；不执行 SVG 脚本、外部网页或任意 EPUB CSS。
- 对明确使用 `opacity:0.4` 标记日文的双语转换文件，只配对紧邻的中日段落，记录配对来源；不再凭“汉字多”推断语言并吞掉正文。
- 支持正式目录与正文中的互相跳转，未命名前付显示为 `Chapter1`。章节选择、上一章／下一章沿阅读顺序导航；重新解析后按源文件和段落重新映射旧进度和书签。
- 保留横排、纵排、日中对照、中文、日文和点击显示译文；排版方向不再自动修改语言选择。双语对照按原书中文在前、日文在后显示。已移除额外加入的目录搜索、字号／行距控件和纵排左右按钮。
- 保留书籍自带译文，章节处理不会为了重新生成而覆盖双语 EPUB 的原译文；清除处理结果只移除生成内容。

目前属于安全的流式阅读器，不是完整 EPUB 浏览器引擎。复杂固定版式、嵌入字体、任意 CSS、交互脚本、DRM 与页码式分页尚不支持；原 EPUB 保留，便于后续扩展。无正式目录时按 spine 与可见标题提供回退目录并保留全部内容。

## 迁移与验证

```powershell
# 停止服务后预览旧数据库中的书籍
conda run -n Tokyo python -X utf8 scripts/migrate_books.py
# 可提供原文件，重建指定书籍的正式目录并映射进度；先备份数据库与旧书籍目录
conda run -n Tokyo python -X utf8 scripts/migrate_books.py --book-id 3 --epub "原始文件完整路径.epub" --apply
```

没有原 EPUB 的旧记录仅迁移已保留内容，并显示需要原文件的说明。迁移报告在 `data/diagnostics/reports/book-migration.json`。旧目录若被 Windows 占用，保留并记录位置，不影响新书名目录使用；切勿为清理目录强制结束无关程序。

测试：`tests/test_epub_reader.py` 覆盖 EPUB3/NCX、层级目录、同章多文件、锚点、SVG 封面、双语、文本安全、原文件保存、独立状态写入、索引恢复与中断恢复。现有 `test_web.py`、`test_book_refresh.py` 继续覆盖 API、进度、书签、重复导入和文件系统删除后的刷新。
