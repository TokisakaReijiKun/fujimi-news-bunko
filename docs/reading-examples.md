# 阅读室示例与声线

阅读室的示例以文件为事实来源，所有浏览器通过本地服务读取同一份数据：

```text
data/articles/examples/
  雪国（川端康成）/
    example.json
    original.txt
  読書の時間（操作示例）/
    example.json
    original.txt
  <自定义标题>/
    example.json
    original.txt
    translation.txt
    audio/
```

`example.json` 保存标题、稳定 ID、正文 SHA-256、译文 SHA-256、声线模式、模型声线 ID、音频版本和浏览器声线名称；`original.txt` 保存 UTF-8 正文；`translation.txt` 按原文段落顺序保存译文；`audio/` 保存按“声线名_示例标题.wav”命名的模型音频。目录名使用标题经过 Windows 安全清理后的结果，标题过长或目录冲突时只追加短稳定 ID。默认两篇只在目录首次不存在时创建，不会在服务重启时覆盖用户修改。

点击“填入示例”选择内容后，可在主表单的“阅读声线”选择本次使用的声线。“增加示例”会预填当前标题、正文和声线；“保存示例”把这些内容保存成模板，同名保存会更新模板。更新前旧目录备份到 `data/backups/example-<ID>/example/`。已有示例逐文件提交，最后替换 `example.json`；活动目录不会改名，已打开的旧音频可继续播放。文件写入中断时从事务日志恢复，日志位于 `data/diagnostics/example-transactions/`。文件缺失或正文哈希不符会报告错误，不自动重置示例。

“保存并阅读”才会通过 ArticleStore 创建日刊文章，并将选定声线交给现有 TTS 系统。模型声线生成本地音频；浏览器声线由阅读器播放时使用，不修改全局默认声线。如果所选声线不可用，系统报告错误。浏览器声线是否可用取决于当前设备的日语语音配置。

选择示例后，网页会随导入请求提交 `example_id`，后端校验标题与正文后复用示例译文和对应声线的有效音频。同一示例、同一正文在同一 CST 日期内复用文章；跨日建立独立文章并复制缓存音频。修改表单标题或正文会解除示例关联，避免把旧译文或音频用于新内容。有效缓存不会触发模型加载。

首次打开更新后的服务页面时，会检查该来源的旧 `fujimi-reader-examples-v1` 浏览器数据，先备份到 `data/backups/examples-browser-<SHA256>.json` 再导入文件。重复迁移不会再次添加，也不会覆盖已经更新的文件示例；同名但正文不同的旧数据会以带“浏览器导入”后缀的标题保留。原浏览器数据保持不变。其他浏览器或其他来源（例如 localhost）的旧数据，需要从对应来源打开更新后的服务页面才能迁移。

使用 `http://127.0.0.1:8427/#reader` 访问。直接打开 HTML 文件不能调用本地服务接口。
