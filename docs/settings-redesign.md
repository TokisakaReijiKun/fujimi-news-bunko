# 设置页视觉重设计提案

本次产物是设置页的独立高保真静态设计稿，没有修改正式前端文件。设计稿以当前设置能力为内容基础，把原来的长表单重排为“状态总览 → 分组设置 → 详情页”的阅读节奏。

## 三个方向

1. **本棚の余白（推荐移动端主方案）**
   - 顶部只保留返回、页面名称和应用标识。
   - 用一张深苔绿色的状态卡回答“朗读、文库、同步现在是否可用”。
   - 首屏按“阅读体验 / 文库与同步 / 日刊”排列；安全、密钥、诊断放到下一层。
   - 适合 375 / 390px 宽度，保留现有主导航与设置页路由。

2. **文庫コントロール（高频操作方案）**
   - 用暖纸色背景降低表单压迫感。
   - 在状态卡下加入横向分组索引，帮助用户快速定位长页面中的类别。
   - 保留底部导航，适合手机端经常在日刊、阅读、书架和设置之间切换。

3. **双栏书房（桌面端 / 平板横屏方案）**
   - 左侧是稳定的设置栏目，右侧是当前栏目内容。
   - 右侧状态摘要固定显示，减少用户来回打开设置确认声线、文库和同步状态的次数。
   - 适合 PC 协同设置较多的桌面宽度，同时可缩放到平板横屏。

## 设计约束

- 保留现有六个主视图与 `settings` hash 路由，不引入新功能。
- 设置项的描述使用短句，当前值始终可见；需要进入详情的行显示箭头。
- 同步仍是用户点击“立即同步”后才开始；设计稿中的“已配对”只代表连接状态，不代表正在同步。
- 保留应用私有 `data/` 目录的说明，避免用户误以为正文存入云端或被哈希改名。
- 颜色、状态徽章与边框有足够对比度；所有图形状态都配有文字，不依赖颜色单独传达状态。
