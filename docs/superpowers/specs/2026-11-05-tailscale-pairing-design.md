# Tailscale 配对联动

用户已确认：开启 PC「文庫互联」时检查并连接已安装的 Tailscale，成功后在它的 IPv4 地址开放同步并生成二维码；未登录时提示用户自行登录；关闭配对不关闭 Tailscale。APK 同步支持 Tailscale 地址。

采用本机 Tailscale CLI 与专用 IP 监听，不使用公网监听或 Tailscale Serve，不更改用户的 DNS、出口节点、账号或访问策略。未安装 Tailscale 时保留原局域网配对。已安装但连接失败不得伪装为成功或静默切回局域网。

现有同步端口 8429、六位配对码、会话令牌、来源检查和内容事务保持。管理页面继续仅监听本机。Tailscale 地址限制为 100.64.0.0/10，普通公网、域名与 IPv6 不在本次范围。

实现分为可注入的 CLI 连接器、PC 同步监听、现有设置面板状态和登录入口、Android 地址策略。create_app() 默认不触发真实 CLI，正式桌面与 Web 启动入口显式启用集成。后台命令使用参数数组、隐藏窗口和超时，不记录原始状态、账号、登录令牌或认证错误体。

用户随后要求「别验证」：仅做离线 mock／核心回归及构建必要检查，不启动 Tailscale、登录、实机或跨网验收。交付须说明这一限制，不请求用户为验收登录。

不迁移或备份用户文库。PC 原位更新，仅替换新 EXE 与变化资源，复用既有 _internal；Android 沿用签名，版本 1.1.3/code26。
