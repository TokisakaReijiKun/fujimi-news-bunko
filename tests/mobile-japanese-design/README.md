| 回放输入 | 原文到同段译文 | 译文到下一段原文 |
| --- | ---: | ---: |
| 普通译文 | 2px | 24px |

## 设计决定

- 淡纸 `#FAF9F5`、墨色 `#292C28`、朱印 `#A3372B`、苔色 `#4E624F`、分隔线 `#DEDFD5`。
- 日文标题与正文使用本机 Noto Serif JP／游明朝；操作、说明和译文使用 Noto Sans JP／系统黑体，中文由系统字体回退补齐。无需联网加载字体。
- 页边距 22–24px，页面标题 30px，文章标题 25px，长文 17px／2.2 行距。状态与辅助信息采用较小字号，正文阅读优先。
- 顶部仅保留紧凑品牌栏。底部五项为日刊、閲読室、書架、辞書、更多，更多展开收藏与設置；六个原有主视图均保留。正文内使用返回按钮与底部朗读区，书籍阅读保留目录与朗读入口。
- 日刊采用一篇带图主文和紧凑列表；收藏用连续文章清单；书架展示书封与继续阅读；设置用可展开的分组行缩短首屏。
- 这是一套可评审的视觉提案。页面数值、新闻、声线、配对状态与书封均为示意，不推断用户的实际数据或设置。
