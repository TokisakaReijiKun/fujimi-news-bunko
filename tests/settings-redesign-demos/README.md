# 设置页重设计 Demo

直接打开 `index.html` 查看总览。三套方案都保持原 APK 的单页纵向结构和现有功能顺序：声线、日刊、书架、Android 本地节点、应用信息、文庫刷新。

| 方案 | 适用场景 | 信息架构 |
| --- | --- | --- |
| A · 原版精修 | 作为正式版基线 | 原顺序 + 清晰卡片层级 + 轻量折叠 |
| B · 紧凑分组 | 设置项较多 | 原顺序 + 更紧凑间距 + 细分隔线 |
| C · 纸张细节 | 强化阅读品牌感 | 原顺序 + 温和纸张色 + 衬线标题 |

页面只演示视觉层级、响应式布局和按钮状态，不替换正式 `static/` 页面。正式接入时继续复用现有 API、`data/` 路径和同步规则。
